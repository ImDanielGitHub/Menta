# Security

Use GitHub's private vulnerability reporting for this repository. Please do
not put exploit details, customer records, credentials, or private screenshots
in a public issue. If private reporting is unavailable, contact
support@menta.quest and ask for a private reporting channel before sending
sensitive material.

Run your own Supabase project and configure your own provider credentials.
The repository does not grant access to the hosted Menta service. Never test
security issues against other people's accounts or a production database.

Before deploying a fork, configure confirmed email sign-ups, bot protection,
password security, per-operation API limits, storage budgets and billing alerts.
The local development settings are not a substitute for reviewing the hosting
provider's production settings. See `docs/SETUP.md`.
